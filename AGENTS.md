# MultiPlayer — Agent Rules

Follow all instructions in [`GEMINI.md`](./GEMINI.md), specifically the **Mandatory Windows <-> Android Cross-Platform Parity Rule** and **Mandatory Dual-Platform Subagent Parity Gate**:

- Every bug report, UI change, or fix applied to the Windows version MUST automatically be audited and verified on the Android version (Android Mobile layout, Android WebView / Capacitor `.apk`, Android Chrome PWA, Notification Shade, Wear OS, and Android Auto) — and vice versa — before completion.
- **Mandatory Design, UX & Fluid Motion Craft Rule (`.agents/skills/ui-motion-craft/SKILL.md`)**: Every UI change MUST use the **True Black default (`theme-amoled`, `#000000`)**, progressive disclosure (`Settings > Advanced Settings` for rarely used actions, `Devices` inside Profile menu, `Audiobooks | Podcasts` filter division with collapsed-by-default series), unified `🔍` Search with in-place result updates (homepage-only, never filtering the left library sidebar), dual-input context menus (PC right-click + Android long-press), left-aligned PC Back button, green-checkmark-only offline indicators (no cloud/folder icons), zero-blink same-view DOM updates, `@starting-style` + `[data-closing]` overlays, and non-destructive Back/`X` close handling.
- **Dual-Platform Subagent / Swarm Parity Gate**: Before releasing or claiming completion on any change (unless explicitly scoped to one platform only), spawn **both** dedicated parity verifiers in parallel — `android-parity-verifier` (defined in `.agents/agents/android-parity-verifier.md`, or `auditor-android` in `/swarm`) and `windows-parity-verifier` (defined in `.agents/agents/windows-parity-verifier.md`, or `auditor-windows` in `/swarm`) — strictly read-only and scoped to platform-specific files/viewports/CI (no re-running full test suites or duplicating `neon-reviewer`'s shared-logic review). If either reports `FAIL`, fix the gap and re-verify before building/pushing.
- Execute the full **5-Step Release Parity Checklist** from `GEMINI.md` on every release:
  1. Audit both Windows (`tauri.localhost` / desktop viewport) and Android (`capacitor://` / `https://localhost` / mobile viewport / Android WebView) platform surfaces via the dual-platform parity verifiers.
  2. Bump `version.json`, `LOCAL_VERSION` / `LOCAL_BUILD` in `src/services/self-updater.js`, `src-tauri/tauri.conf.json`, and `src-tauri/Cargo.toml`.
  3. Run `node scripts/prepare-tauri-ui.mjs` and `cargo build --release --manifest-path src-tauri/Cargo.toml`.
  4. Stop any running `Audiobook Player` / `MultiPlayer` process, copy the release `.exe` to both `d:\Code\Audiobook\` and `C:\Users\ecmat\OneDrive\Desktop\`, and verify matching `Get-FileHash` SHA256.
  5. Run `node --test`, `git-secret-shield`, commit, `git push origin main`, and verify/report the GitHub Actions run status whenever workflows or native Android code changed.
